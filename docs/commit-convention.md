# 커밋 컨벤션

## 기본 형식

커밋 메시지는 아래 형식을 사용합니다.

```text
타입: 한글 커밋명
```

예시:

```text
feat: 로고 자산 교체
fix: 사업자등록번호 줄바꿈 수정
docs: 콘텐츠 전략 정리
refactor: 히어로 섹션 구조 정리
style: 푸터 여백 조정
chore: 원격 저장소 연결
```

## 타입 규칙

- `feat`: 기능 추가 또는 사용자 경험 변화
- `fix`: 버그 수정
- `docs`: 문서 추가 또는 수정
- `refactor`: 동작 변화 없는 구조 개선
- `style`: 시각 스타일 조정
- `chore`: 설정, 빌드, 환경 정리

## 작성 규칙

- 콜론 뒤 제목은 한글로 작성합니다.
- 제목은 짧지만 무엇이 바뀌었는지 바로 알 수 있게 씁니다.
- `feat: homepage update` 같은 영어 제목은 사용하지 않습니다.
- 한 커밋에 여러 성격이 섞이면 주된 목적 기준으로 타입을 고릅니다.
