# 디자인 가이드

## 디자인 목표

광림전산 홈페이지는 화려한 브랜드 페이지보다 신뢰감 있는 B2B 안내 페이지에 가깝게 디자인합니다. 첫인상은 단정하고, 정보는 빠르게 찾을 수 있어야 하며, 문의 행동은 자연스럽게 이어져야 합니다.

## 톤앤매너

- 차분함
- 신뢰감
- 실용성
- 지역 기반 업체의 현실감
- 과장되지 않은 전문성

## 로고 사용 기준

- 헤더: 컬러 로고 기본 사용
- 히어로: 로고를 과시용으로 크게 반복하지 않음
- 푸터: 화이트 로고 사용 가능
- 로고 하단의 작은 문구가 가독성을 해치면 제거한 버전을 우선 사용

## 화면 구성 원칙

### 첫 화면

- 로고보다 핵심 메시지와 문의 버튼이 우선입니다.
- 우측 정보 카드는 장식보다 문의 판단에 필요한 내용만 담습니다.
- 영어 라벨이나 브랜드 소개용 블록은 최소화합니다.

### 정보 밀도

- 섹션 수는 적게, 정보 밀도는 명확하게 유지합니다.
- 한 섹션 안에서 역할이 겹치면 병합을 우선 검토합니다.
- 반복되는 CTA는 줄이고, 실제 필요한 위치에만 둡니다.

### 카드 사용

- 카드 안에는 행동을 돕는 정보만 넣습니다.
- 카드가 카드 안에 중첩되지 않도록 합니다.
- 장식성 카드보다 목록/표/요약 형태를 우선합니다.

## 타이포그래피

- Pretendard 사용
- 제목은 과장하지 않고 강약만 또렷하게 줍니다.
- 한국어 줄바꿈은 의미 단위로 처리합니다.
- 한 줄 마지막에 한 글자만 떨어지는 상황은 피합니다.

## 반응형 기준

- 모바일에서 먼저 읽히는 구조를 우선합니다.
- 헤더 로고, 전화 버튼, 주요 CTA는 좁은 폭에서도 깨지지 않아야 합니다.
- 사업자등록번호, 전화번호 같은 핵심 텍스트는 필요 시 줄바꿈 방지 처리합니다.

## 금지 방향

- 영어 중심 라벨 남용
- 내부 보고용 같은 제목
- 브랜드 과시용 대형 보조 블록
- 정보 없이 분위기만 만드는 장식 요소
