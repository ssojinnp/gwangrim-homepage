# 콘텐츠 전략

## 목표

광림전산 홈페이지의 문구는 회사 내부 담당자 기준이 아니라 실제 고객 기준으로 읽혀야 합니다. 방문자는 사이트에 들어오자마자 다음 네 가지를 바로 이해해야 합니다.

1. 이 회사는 무엇을 하는 곳인지
2. 내 문의도 가능한지
3. 어떤 품목을 취급하는지
4. 어떻게 문의하면 되는지

## 핵심 메시지

### 메인 메시지

- 전산용품부터 인쇄·판촉 제작까지 한 곳에서 문의할 수 있습니다.
- 관공서, 기업체, 개인 고객 모두 문의할 수 있습니다.
- 창원 마산 지역 기반으로 납품과 제작 상담을 진행합니다.

### 보조 메시지

- 필요한 품목과 수량을 알려주시면 확인 후 안내드립니다.
- 소량 제작 문의도 가능합니다.
- 전화, 팩스, 이메일로 문의할 수 있습니다.

## 문구 원칙

### 고객 중심 표현 사용

좋은 예:
- 빠른 문의 안내
- 문의 전에 확인해 주세요
- 주요 품목 및 제작 서비스
- 누구나 문의 가능합니다

피해야 할 예:
- 담당자 확인용 핵심 정보
- PROCUREMENT BRIEF
- BRAND SIGNATURE
- 내부 검토 자료
- 핵심 솔루션

### 내부용 표현 금지

문구는 사용자의 행동을 돕는 방향이어야 합니다. 방문자가 이해하기 어려운 내부 시점 표현은 사용하지 않습니다.

- `담당자`, `브리프`, `내부`, `확인용` 같은 표현은 우선적으로 제거합니다.
- 영어 라벨은 꼭 필요한 경우가 아니면 사용하지 않습니다.
- 의미가 모호한 표현보다 실제 품목, 실제 행동, 실제 문의 방식을 씁니다.

## 섹션별 카피 방향

### 첫 화면

- 회사가 무엇을 하는지 한 문장으로 설명합니다.
- 로고보다 메시지와 문의 동선이 우선입니다.
- CTA는 `견적 문의하기`, `전화 문의`처럼 행동 중심으로 씁니다.

### 품목/서비스 섹션

- 고객이 찾는 품목 기준으로 분류합니다.
- 품목과 제작 서비스를 구분하되, 전체적으로는 "무엇을 할 수 있는지"가 한눈에 보이게 구성합니다.

### 문의 섹션

- 문의 전에 어떤 정보를 보내야 하는지 명확히 안내합니다.
- `품목명`, `수량`, `희망 납기`, `수령 방식`처럼 실무에 필요한 표현을 사용합니다.

### 회사 정보 섹션

- 대표자, 전화, 팩스, 이메일, 주소, 사업자등록번호를 정확하게 노출합니다.
- 신뢰를 위한 정보는 숨기지 말고 단정하게 정리합니다.

## 추천 문구 예시

### 히어로 제목 예시

- 전산용품부터 인쇄·판촉 제작까지 한 곳에서 문의하세요
- 필요한 업무 물품과 제작물을 함께 안내해드립니다

### 우측 카드 제목 예시

- 빠른 문의 안내
- 문의 전 확인사항
- 납품 및 제작 문의 안내

### 문의 섹션 제목 예시

- 문의 전에 아래 내용을 알려주시면 더 빠르게 안내해드립니다
- 필요한 내용을 보내주시면 확인 후 연락드립니다
