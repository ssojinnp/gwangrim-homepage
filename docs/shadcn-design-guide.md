# shadcn 디자인 가이드

## 디자인 목표

광림전산 홈페이지는 지역 기반 납품·제작 상담 업체의 신뢰감을 전달해야 한다. 과장된 장식보다 명확한 정보, 안정적인 여백, 읽기 쉬운 타이포그래피, 빠른 문의 동선이 중요하다.

## 핵심 인상

- 신뢰감 있는 납품처
- 관공서와 기업체가 보기에 안정적인 화면
- 개인 고객도 부담 없이 문의할 수 있는 접근성
- 제품 판매 페이지가 아니라 상담과 견적 문의 중심의 회사 소개

## 디자인 원칙

1. 첫 화면에서 회사명, 주요 업무, 문의 버튼을 명확히 보여준다.
2. 긴 한국어 제목은 의미 단위로 줄바꿈한다.
3. 카드는 정보 묶음에만 사용하고, 장식용 카드는 만들지 않는다.
4. 색상은 파란색, 흰색, 회색을 기본으로 하고 강조 색은 제한적으로 사용한다.
5. 모든 UI는 모바일에서 먼저 자연스럽게 읽혀야 한다.
6. 반복되는 UI는 shadcn 컴포넌트 variant로 관리한다.

## 컬러 방향

- 메인 파랑: 신뢰감, 회사명, 주요 버튼, 핵심 강조
- 짙은 파랑: 헤더 로고, 푸터, 절차 섹션 배경
- 연한 파랑: 보조 버튼, 정보 배경
- 회색: 본문 설명, 구분선, 카드 배경
- 녹색: 개인 고객 가능, 체크 포인트, 가능 상태 표시

## 타이포그래피 방향

- 폰트: Pretendard
- Hero 제목: 굵고 크지만 줄 수를 제어한다.
- 섹션 제목: 2줄 이하로 유지한다.
- 본문: 16~18px, 줄간격은 넉넉하게 둔다.
- 카드 제목: 20~22px 수준으로 유지한다.
- 버튼: 14~15px, 굵게 표시한다.

## 반응형 기준

### 모바일

- 헤더는 브랜드, 전화 버튼, 가로 스크롤 메뉴로 구성한다.
- Hero 제목은 모바일 전용 줄바꿈을 사용한다.
- 버튼은 세로로 쌓고 전체 너비를 사용한다.
- 카드와 문의 정보는 1열로 표시한다.

### 태블릿

- 고객 유형과 품목 카드는 2열을 기본으로 한다.
- Hero 정보 패널은 텍스트 아래에 배치한다.

### 데스크톱

- Hero는 텍스트와 상담 패널을 2열로 배치한다.
- 서비스 카테고리는 중요도에 따라 2~3열로 조정한다.
- 문의 섹션은 연락처와 체크리스트를 2열로 배치한다.

## 페이지 섹션 기준

1. Header
   - 브랜드와 핵심 메뉴, 전화 CTA를 제공한다.

2. Hero
   - 회사명, 주요 업무, 문의 CTA, 상담 요약을 제공한다.

3. Trust Bar
   - 관공서, 기업체, 개인 고객, 제작 서비스를 짧게 요약한다.

4. Audience
   - 고객 유형별로 어떤 문의가 가능한지 안내한다.

5. Services
   - 취급 품목을 분류해 보여준다.

6. Production
   - 제작 서비스만 별도로 구분한다.

7. Process
   - 문의부터 납품까지의 과정을 설명한다.

8. Contact
   - 전화, 팩스, 이메일, 주소, 견적 문의 체크리스트를 제공한다.
