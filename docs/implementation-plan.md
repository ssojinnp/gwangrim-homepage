# 구현 계획

## 현재 개편 목표

현재 사이트는 "회사 소개"보다 "문의와 안내"의 기능을 더 명확하게 수행하도록 구조를 정리해야 합니다. 따라서 다음 방향으로 개편합니다.

1. 내부용 문구 제거
2. 섹션 수 축소 또는 병합
3. 핵심 정보 중심 재배치
4. 로고는 보조가 아니라 식별 역할로만 사용

## 우선 작업 항목

### 1. 히어로 정리

- 장식성 블록 제거
- 핵심 메시지와 문의 CTA 유지
- 우측 카드는 `빠른 문의 안내` 성격으로 단순화

### 2. 고객 안내 구조 정리

- `AudienceSection`의 별도 유지 여부 검토
- 필요한 경우 히어로 보조 문구로 흡수

### 3. 품목 섹션 재구성

- `ServicesSection`과 `ProductionSection` 병합 여부 검토
- 사용자가 이해하기 쉬운 범주로 재정렬

### 4. 문의 섹션 문구 수정

- 내부 시점 표현 제거
- 고객이 바로 행동할 수 있는 문구로 교체

## 검증 항목

- `npm run build` 성공
- 모바일/데스크톱에서 가로 스크롤 없음
- 헤더/히어로/푸터의 로고 가독성 확보
- 사업자 정보 정확성 유지
- 영어 라벨 제거 또는 최소화
